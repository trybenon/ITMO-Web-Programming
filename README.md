# ITMO-Web-Programming

---

## 🧩 Задания и лабораторные работы

В рамках курса предусмотрены **4 лабораторные работы**, направленные на практическое освоение веб-технологий:

---

### 🔹 Лабораторная работа #1

**Тема:** Работа с FastCGI и Apache httpd

**Основные разделы:**

* Основы HTTP: запросы, ответы, методы, коды статусов
* HTML, CSS, JavaScript, AJAX, jQuery

**Вопросы к защите:**

> Протокол HTTP, DOM, формы, CSS, LESS/Sass/SCSS, AJAX, FastCGI

---

### 🔹 Лабораторная работа #2

**Тема:** Разработка веб-приложения на сервлетах и JSP

**Основные разделы:**

* Проверка попадания точки в область на координатной плоскости
* MVC, ControllerServlet, AreaCheckServlet, JSP-страницы

**Вопросы к защите:**

> Сервлеты, контейнеры, сессии, JSP, EL, шаблоны MVC

---

### 🔹 Лабораторная работа #3

**Тема:** Приложение на JavaServer Faces (JSF)

**Основные разделы:**

* Стартовая и основная страницы с интерактивными элементами
* Работа с компонентами PrimeFaces и ICEfaces
* Использование базы данных PostgreSQL через JPA/ORM

**Вопросы к защите:**

> JSF, managed beans, конвертеры и валидаторы, навигация, ORM/Hibernate/EclipseLink

---

### 🔹 Лабораторная работа #4

**Тема:** Технологии Java EE и Spring

**Основные разделы:**

* EJB, JMS, JavaMail, JAX-RS, JAX-WS
* Разработка REST API, работа с React и Angular

**Вопросы к защите:**

> IoC, CDI, транзакции, Spring Security, Redux, ReactRouter, Angular-компоненты

---

## ⚙️ Технологии и инструменты

**Backend:**
Java EE, Spring, Servlets, JSP, JSF, JPA, Hibernate, EclipseLink

**Frontend:**
HTML, CSS, LESS/Sass/SCSS, JavaScript, AJAX, jQuery, React, Angular

**СУБД:**
PostgreSQL

**Серверы приложений:**
WildFly, Apache httpd

**Прочее:**
FastCGI, PrimeFaces, ICEfaces
