---

## 🛠 Технологии и инструменты

* **Backend:** Java EE, Spring, Servlets, JSP, JSF, JPA, Hibernate, EclipseLink.
* **Frontend:** HTML, CSS, LESS/Sass/SCSS, JavaScript, AJAX, jQuery, React, Angular.
* **Базы данных:** PostgreSQL.
* **Серверы и окружение:** WildFly, Apache httpd, FastCGI.
* **UI-компоненты:** PrimeFaces, ICEfaces.

### [🔹 Лабораторная работа #2](https://github.com/trybenon/ITMO-Web-Programming/tree/lab2)
> **Тема:** Разработка веб-приложения на сервлетах и JSP  

Разработка веб-приложения в соответствии с шаблоном **MVC**, определяющего попадание точки на координатной плоскости в заданную область. Приложение разворачивается на сервере **WildFly**.

**Архитектура приложения:**
* `ControllerServlet` — определяет тип запроса и делегирует его обработку.
* `AreaCheckServlet` — проверяет попадание точки в область и формирует ответ.
* `JSP-страница` — форма ввода данных и отображение результатов.

**Функционал интерфейса (JSP):**
* Валидация вводимых значений с помощью JavaScript.
* Интерактивное изображение области: по клику определяются координаты, отправляется запрос на сервер, и на графике отрисовывается новая точка.
* Таблица с историей предыдущих проверок (хранится в контексте приложения/сессии/Bean).
